# Indian Domestic Flights Analytics (2019–2025)

**Status:** In Progress

## Overview

An end-to-end data analytics project exploring Indian domestic flight data using Python and MySQL. The project focuses on data preparation, data quality validation, SQL-based analysis, and extracting business insights from airline, route, fare, and journey information.

## Objectives

- Prepare and validate flight data using Python and Pandas.
- Store structured data in MySQL for analytical querying.
- Investigate airline performance, route patterns, fare distributions, and journey durations.
- Translate query results into meaningful business insights.

## Dataset

- **Source:** Kaggle — Indian Domestic Flights Dataset (2019–2025)
- **Records:** 15,000
- **Raw data:** Preserved separately from the processed dataset.

The repository documents the data preparation process and analytical workflow. Dataset availability and reuse are subject to the original source's licence.
